# runtime

Проверка явного контекста dispatcher и reader lease перед загрузкой инструментов.
Прямой global entrypoint делегирует исполнение закреплённому bootstrap; модуль
не выбирает store или другую установку самостоятельно.

## Вложенные каталоги

- [tests/](tests/) — тесты контекста и установленной копии; в поставку не идут
