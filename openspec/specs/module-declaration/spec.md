# module-declaration Specification

## Purpose
Как модуль репозитория symphysis объявляет себя: README каталога модуля несёт имя и род в разборчивом для скрипта виде и описывает вложенные каталоги первого уровня.

## Requirements

### Requirement: README модуля несёт имя и род во frontmatter
Каждый каталог модуля в репозиториях ядра и плагина SHALL нести `README.md`, который начинается frontmatter YAML с полями `name` — имя модуля — и `kind` — `доменный` или `технический` (F-02, F-03, F-16, F-21, F-39). Имя модуля MAY отличаться от имени каталога (F-21).

#### Scenario: README модуля ядра
- **GIVEN** каталог модуля `decisions/` ядра
- **WHEN** тест структуры читает его `README.md`
- **THEN** файл начинается frontmatter с `name: decisions` и `kind: доменный`

#### Scenario: Род вне двух значений
- **GIVEN** README модуля с `kind: служебный`
- **WHEN** выполняется тест структуры
- **THEN** тест красный и называет каталог модуля и значение `kind`

#### Scenario: README без frontmatter
- **GIVEN** каталог модуля, чей `README.md` не начинается frontmatter
- **WHEN** выполняется тест структуры
- **THEN** тест красный и называет каталог

#### Scenario: Пустое имя модуля
<!-- F-47 -->
- **GIVEN** README модуля с `name: ""` или `name:` из одних пробелов
- **WHEN** выполняется тест структуры
- **THEN** тест красный и называет каталог

#### Scenario: Два модуля с одним именем
<!-- F-48 -->
- **GIVEN** два каталога модулей ядра с `name: decisions`
- **WHEN** выполняется тест структуры
- **THEN** тест красный и называет оба каталога

### Requirement: README модуля описывает вложенные каталоги первого уровня
README модуля SHALL описывать модуль и каждый его вложенный каталог первого уровня: ссылкой на каталог и строкой о нём (F-03).

#### Scenario: Вложенный каталог описан
- **GIVEN** модуль с вложенным каталогом `tests/`
- **WHEN** тест структуры читает README модуля
- **THEN** в README есть ссылка на `tests/` и строка о нём

#### Scenario: Каталог появился без описания
- **GIVEN** в модуле появился вложенный каталог, которого README модуля не называет
- **WHEN** выполняется тест структуры
- **THEN** тест красный и называет модуль и каталог

#### Scenario: Вложенный каталог вне git
<!-- F-49 -->
- **GIVEN** в модуле есть `__pycache__/`, которого нет в git
- **WHEN** выполняется тест структуры
- **THEN** тест его не требует: в счёт идут вложенные каталоги, которые знает git

### Requirement: README модуля не называет каталог, которого нет
README модуля MUST NOT называть вложенный каталог, которого в модуле нет: тест структуры SHALL сверять ссылки README с каталогами модуля в обе стороны (F-03, F-55; проверка — тест).

#### Scenario: Ссылка на удалённый каталог
<!-- F-55 -->
- **GIVEN** README модуля ссылается на `fixtures/`, а каталога в модуле нет
- **WHEN** выполняется тест структуры
- **THEN** тест красный и называет модуль и ссылку
