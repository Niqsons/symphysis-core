# user-installation Specification

## Purpose
Определяет пользовательскую поставку symphysis, её обновление и явную смену режима без переноса состояния store в общий runtime.

## Requirements

### Requirement: Пользовательская установка содержит общий продукт
Global-установка SHALL предоставлять пользователю общий runtime, ресурсы, справку, скиллы и поддерживаемые клиентом тела агентов. Для работы в выбранном store SHALL быть достаточно его состояния, настроек и необходимой инициализации без проектной копии общего runtime (global-user-install/F-03, global-user-install/F-01, global-user-install/F-02).

#### Scenario: Клонированный store использует пользовательскую поставку
- **GIVEN** пользователь клонировал store и установил symphysis в режиме global
- **WHEN** он инициализирует этот store и выполняет путь от намерения до архивирования изменения
- **THEN** общие инструменты и ресурсы берутся из пользовательской поставки, а изменение и его архив остаются в выбранном store

### Requirement: Local и global являются самостоятельными режимами
Symphysis SHALL поддерживать полноценный цикл изменения отдельно в project-local и отдельно в global режиме. Local SHALL оставаться действующим режимом, а совместная работа local и global в одном проекте SHALL NOT становиться условием работоспособности любого из них (global-user-install/F-13).

#### Scenario: Local работает без пользовательской поставки
- **GIVEN** в проекте установлена project-local поставка, global-установки нет
- **WHEN** пользователь выполняет цикл от намерения до архивации
- **THEN** цикл использует local-поставку без требования установить global

#### Scenario: Global работает без проектной поставки
- **GIVEN** есть global-установка и инициализированный совместимый store без local-поставки
- **WHEN** пользователь выполняет цикл изменения
- **THEN** отсутствие проектной копии runtime не препятствует выполнению шагов

### Requirement: У пользователя одна активная global-поставка
Global-установка SHALL иметь одну активную пользовательскую поставку. Совместимое обновление SHALL предоставлять общие ресурсы этой поставки всем использующим её store; управление несколькими закреплёнными за store версиями runtime SHALL NOT требоваться для первого выпуска (global-user-install/F-11).

#### Scenario: Обновление используется двумя совместимыми store
- **GIVEN** два store используют одну global-поставку и совместимы с её обновлением
- **WHEN** пользователь обновляет global-поставку и вызывает инструмент в каждом store
- **THEN** оба вызова используют обновлённую активную поставку без установки отдельных закреплённых версий

### Requirement: Установка сохраняет границы собственных файлов
Установка и обновление SHALL различать собственные файлы поставки и пользовательские изменения либо чужие файлы в местах назначения. Пользовательские и чужие файлы MUST NOT заменяться автоматически; конфликт SHALL быть назван пользователю без выдачи конфликтующего файла за успешно обновлённую часть поставки (global-user-install/F-12, global-user-install/F-03).

#### Scenario: Пользователь изменил поставленный файл
- **GIVEN** файл в месте установки отличается от собственной копии, ранее поставленной symphysis
- **WHEN** обновление затрагивает этот файл
- **THEN** изменение пользователя сохраняется, конфликт назван, файл не объявлен успешно обновлённым

#### Scenario: Место назначения занято чужим файлом
- **GIVEN** место назначения нужного ресурса занято файлом, который не принадлежит поставке symphysis
- **WHEN** выполняется установка
- **THEN** чужой файл не заменён автоматически и пользователь видит конфликт

### Requirement: Смена режима выполняется явно для выбранного store
Миграция между local и global SHALL быть явным действием пользователя для выбранного store. До переключения SHALL быть показаны найденные собственные копии и конфликты; переключение SHALL выполняться после подтверждения. Установка global сама по себе MUST NOT мигрировать остальные store или автоматически разрешать конфликты смешанной установки (global-user-install/F-12, global-user-install/F-13).

#### Scenario: Пользователь подтверждает переход выбранного store
- **GIVEN** выбраны store и переход с local на global, проверка нашла собственные копии и конфликт
- **WHEN** пользователь просматривает результат и ещё не подтвердил переключение
- **THEN** режим store и найденные файлы не переключены автоматически

#### Scenario: Другой store не переходит вслед за выбранным
- **GIVEN** пользователь просмотрел собственные копии без конфликтов и подтверждает переход одного из двух store с local на global
- **WHEN** выполняется миграция выбранного store
- **THEN** выбранный store использует global, режим и файлы второго store не меняются, пользовательские изменения выбранного store не заменяются автоматически
