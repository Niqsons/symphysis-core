# Native-приёмка: фактическое состояние, 2026-11-09

Проверяется контур разработки на Windows, отдельно от требований к установке продукта.
Тестовая Windows-учётная запись — `test-user`; действующие настройки и credentials владельца
не используются как фикстуры. Временные данные клиентов находятся на X.

Владелец исключил Claude из этой приёмки: «На Claude работу не тестируем.»
OpenCode IDE отложен в отдельную сессию, B-64 и задачи 9.2–9.4 остаются открытыми.
Native OpenCode CLI проверяется через подписку OpenCode Go по отдельному разрешению владельца.

## Что выполнено

| Проверка | Фактический результат | Предел свидетельства |
| --- | --- | --- |
| Windows identity | Дочерние процессы подтвердили SID тестовой учётной записи, ограниченный token и свои HOME/TEMP на X | Сам по себе отдельный пользователь не задаёт правила всех инструментов модели |
| Четыре независимые установки | Codex local/global и OpenCode local/global прошли CLI preflight и чтение канонического brainstorm через dispatcher | Это запуск CLI, ещё не модельный флоу |
| Codex native discovery | В обоих режимах клиент обнаружил 7 skills и 8 workflow-носителей с ожидаемыми путями и scope | Загрузка TOML-водителя и получение тела моделью ещё не доказаны |
| OpenCode native discovery | В обоих режимах обнаружены 7 skills с точными телами, 5 drivers с точными телами и 8 commands; три встроенных скилла распознаны отдельно | Чтение registry API не подтверждает получение инструкций моделью |
| Сохранность стенда | 390 исходных файлов и manifest сохранены; изменения ограничены разрешёнными клиентскими cache-файлами | Не распространяется на ещё не выполненные модельные этапы |
| Codex global root на Windows | Временная ссылка в Known Folder тестового пользователя указывала на X; после каждого запуска удалена, цель сохранена | Подмена HOME сама по себе не была выдана за native global discovery |
| Авторизация | Нативные Codex ChatGPT и OpenCode Go завершили вход в новые собственные хранилища тестового пользователя | Значения auth не читаются helper-скриптами и не включаются в отчёт |
| Каталоги моделей | Codex вернул 8 моделей, default `gpt-6.1-sol`; Go вернул 29, включая `opencode-go/glm-5.2` | Наличие в каталоге не доказывает успешный inference |
| OpenCode permissions | Нативная оценка 24 правил прошла; проверены allow/deny, сохранённые роль/каталог/permissions и PID собственного сервера | Это оценка правил API, ещё не выполнение каждого инструмента и не OS sandbox |

При сравнении OpenCode body сохраняются исходные UTF-8 байты, CRLF и завершающий перевод
строки. Предыдущие отрицательные результаты из-за нормализации текста не переписаны;
исправленный сборщик затем дважды получил полный успешный результат четырёх случаев.

## Блокер Codex

Явная проба Windows MXC завершилась до выполнения синтетических read/write canary:
клиент сообщил, что механизм недоступен. Процесс завершён, fallback не использовался,
системные функции и ACL не менялись. Модель в этой пробе не запускалась.

Нельзя считать read-only или workspace-write доказательством запрета чтения вне стенда.
Полный Codex intent→archive остаётся непроверенным до подходящего ограниченного режима.
Возможность отдельного запроса без файловых инструментов исследуется; такой запрос мог бы
подтвердить только получение текста моделью, а не полный флоу.

## Что ещё не выполнено

Модельные запросы, native вызов водителей, guard до первой записи и учебный intent→archive
пока не подтверждены. Пункты 10.1–10.6 и 11.2–11.4 не отмечаются выполненными по одному
успеху discovery или permissions. Claude не засчитывается как прошедший клиент.

Сырые auth-ответы, ключи, account labels, cookies и содержимое клиентских credential stores
не являются свидетельствами этого отчёта и не включаются в git. Локальные metadata receipts
и точные команды продолжения перечислены в текущем handoff вне git.
