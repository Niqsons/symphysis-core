# Проверка предполагаемой коллизии глобальных агентов

Дата: 2026-11-08. Источник — локальный клон OpenCode `X:/opencode`, commit `ffe6fed583`, package 2.2.5. Проверялись исходники, сервер и модель не запускались, личные конфиги не читались.

Изначальная гипотеза: если поставить нативные глобальные агенты symphysis для Claude Code и OpenCode, OpenCode автоматически прочитает также Claude agents и объединит два одноимённых тела.

Гипотеза не подтверждена:

- `packages/core/src/config/plugin/compatibility.ts:44–55,78–80` добавляет из compatibility roots только `skills` и меняет `ctx.skill`.
- `packages/core/src/config.ts:363–373,489–496` разделяет обычные config entries и compatibility roots.
- `packages/core/src/config/plugin/agent.ts:43–55` читает `config.entries()`. Слияние агентных определений по ID в `:75–104` само по себе не означает чтение Claude agent roots.

Для попадания Claude agent в native sources потребовалась бы явная копия, ссылка или конфигурация. Одной глобальной установки в каталог Claude для утверждения такой коллизии недостаточно.

Поэтому кандидат пробы на этом предположении не создаётся. Это не доказывает поведение бинарника при любых настройках и не отменяет уже записанные различия native discovery в F-14. Проверки нативных форматов и изолированных клиентских сессий остаются в приёмке `client-installation`.
