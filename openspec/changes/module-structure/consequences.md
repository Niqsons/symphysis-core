## Pre-mortem

1. Плагин перестаёт проверяться на настоящем ядре молча: тесты опознают ядро по `tools/journal.py`, после перестройки без `SYMPHYSIS_ROOT` они пропускаются, а прогон зелёный — кандидат: F-61
2. Тесты модулей плагина молча выпадают из прогона: `build.mjs` собирает только `test/unit/`, а тесты переезжают в каталоги модулей — кандидат: F-62
3. Установленная копия у пользователя падает на импорте файла, рождённого разрезом `journal_render.py` или `journal_apply.py`: payload собирается списком `FILES`, а тесты ядра идут из исходника с каталогами модулей в `sys.path` — кандидат: F-65
4. Предупреждение о старом payload исчезает: признак клона ищет каталог `skills/`, которого в модульной раскладке нет (ветка описи F-60)
