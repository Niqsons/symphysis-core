# Spec Delta

## MODIFIED Requirements

### Requirement: Заданный `SYMPHYSIS_ROOT` без ядра — падение, а не пропуск
Тесты плагина SHALL падать, если `SYMPHYSIS_ROOT` задан, а ядра по этому пути нет. Без заданной переменной поведение SHALL оставаться прежним (`docs/repo-contract.md`, F-20).

#### Scenario: Опечатка в пути
- **GIVEN** `SYMPHYSIS_ROOT` указывает на каталог, где нет `journal.py` ядра ни в одном месте раскладки исходников (F-09, F-26)
- **WHEN** выполняется `npm test`
- **THEN** прогон красный и называет причину, тесты на настоящем ядре не пропущены молча

#### Scenario: Пустая переменная
- **GIVEN** `SYMPHYSIS_ROOT` равен пустой строке
- **WHEN** выполняется `npm test`
- **THEN** это считается как незаданная переменная
