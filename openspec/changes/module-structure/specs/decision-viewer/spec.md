# Spec Delta

## MODIFIED Requirements

### Requirement: Просмотрщик — один HTML из своего шаблона с тремя режимами
`render-html` SHALL собирать `symphysis.html` из `decisions.json` по шаблону `playground-template.html` (F-26) в один файл с режимами «решения», «проверка» (только чтение) и «атака» (строки `attack/*.md`, переданных `--attack`); состояние человека SHALL жить в browser storage; страница SHALL собирать промпт возврата кнопкой и SHALL NOT писать на диск (журнал `symphysis-schema`: F-26.B, F-17.D).

#### Scenario: Сборка с атакой
- **GIVEN** годный `decisions.json` и `attack/decisions.md` с валидной таблицей
- **WHEN** выполняется `render-html decisions.json --out symphysis.html --attack attack/decisions.md`
- **THEN** код 0, `symphysis.html` — один файл с переключателем трёх режимов и хешем журнала в шапке

#### Scenario: Битый файл атаки
- **GIVEN** `attack/decisions.md`, строка таблицы которого после разбора по соглашению markdown даёт не 7 ячеек
- **WHEN** выполняется `render-html … --attack attack/decisions.md`
- **THEN** stderr называет файл и строку, код 2, HTML не пишется

#### Scenario: Черта в backticks и экранированная черта
- **GIVEN** строка атаки с ячейкой `` `grep -c '| справка |'` `` и ячейкой «есть \| нет»
- **WHEN** выполняется `render-html … --attack`
- **THEN** строка разобрана в 7 ячеек, код 0, в HTML ячейки показаны с чертой как текстом

#### Scenario: Экранированная косая и незакрытый backtick
- **GIVEN** строка атаки с ячейкой, где стоит `\\|`, и другая строка с незакрытым backtick в ячейке
- **WHEN** выполняется `render-html … --attack`
- **THEN** в первой `\\` — литеральная косая, следующая черта — разделитель; вторая даёт ошибку с номером строки, код 2

#### Scenario: Пустая ячейка
- **GIVEN** строка атаки с пустой ячейкой «Инвариант» у строки, не относящейся к покрытию
- **WHEN** выполняется `render-html … --attack`
- **THEN** ошибка с номером строки и именем столбца «Инвариант», код 2; счёт ячеек этот случай не ловит

#### Scenario: Соседнего файла нет
- **GIVEN** страница, открытая там, где файла mermaid нет
- **WHEN** человек работает с журналом
- **THEN** все режимы и промпт возврата работают

### Requirement: `render-html` встраивает снимок справки, сбой страницу не роняет
`render-html` SHALL считать данные справки кодом `step_help.py` (F-26) от корня, взятого из пути журнала, и встраивать их в страницу со временем снятия и командой пересборки (F-21, F-34, F-58, F-67). Сбой расчёта SHALL NOT менять код выхода и ронять страницу: журнал показан, панель называет причину (F-34). Страница SHALL NOT обновлять снимок сама: новый снимок даёт повторная `render-html` (F-21). Путь по умолчанию SHALL NOT появляться, файл задаёт `--out` (F-30).

#### Scenario: Снимок на странице
- **GIVEN** активное изменение и форк на месте
- **WHEN** выполняется `render-html decisions.json --out symphysis.html`
- **THEN** код 0, в панели справки текущий шаг и время снятия

#### Scenario: Форка нет
- **GIVEN** журнал активного изменения, `openspec` не найден
- **WHEN** выполняется `render-html decisions.json --out symphysis.html`
- **THEN** код 0, все режимы и промпт возврата работают, панель справки говорит, что `openspec` не найден

#### Scenario: Файлы изменились после снимка
- **GIVEN** страница собрана, затем появился `design.md`
- **WHEN** человек открывает страницу снова
- **THEN** панель показывает прежний шаг и прежнее время снятия; после повторной `render-html` — новый шаг и новое время

#### Scenario: Журнал из другого проекта
- **GIVEN** журнал `A/openspec/changes/demo/decisions.json`, вызов из проекта `B` со своим `demo`
- **WHEN** выполняется `render-html`
- **THEN** форк зовётся с корнем `A`, справка о шаге из `A`

#### Scenario: Команда пересборки рядом со снимком
- **GIVEN** снимок на странице
- **WHEN** человек открывает справку
- **THEN** рядом со временем снятия готовая команда пересборки для этого изменения

### Requirement: Скилл просмотрщика знает о внесении кнопкой
Скилл `symphysis-viewer` (F-26) SHALL говорить, что слово приходит промптом в чат или внесено кнопкой: тогда есть файл в `answers/` и событие хука (F-34). Скилл SHALL называть `.symphysis/viewer/` черновиками человека, а не словом, и SHALL требовать перечитать журнал перед записью. Внесённое кнопкой агент SHALL NOT вносить второй раз. Строку о `scheme.md` скилл SHALL называть сигналом: работу она не прерывает (слово к F-74).

#### Scenario: Текст скилла
- **GIVEN** файл скилла
- **WHEN** тест ищет `events.jsonl`, `.symphysis/viewer/` и `answers/`
- **THEN** все три названы

#### Scenario: Агент получил событие
- **GIVEN** вывод хука о внесённом кнопкой
- **WHEN** агент продолжает работу по скиллу
- **THEN** он перечитывает журнал и не зовёт `apply` на тот же промпт; судит ревью изменения чтением скилла

#### Scenario: Черновик не слово
- **GIVEN** в `.symphysis/viewer/demo.json` выбран вариант, внесения не было
- **WHEN** агент читает журнал
- **THEN** этот выбор он не считает решением человека

#### Scenario: Строка о схеме
- **GIVEN** вывод хука о `scheme.md`
- **WHEN** агент продолжает работу по скиллу
- **THEN** работа не прерывается, решения по-прежнему в журнале; судит ревью изменения чтением скилла

## ADDED Requirements

### Requirement: Строка таблицы атаки разбирается по соглашению markdown
Часть требования «Просмотрщик — один HTML из своего шаблона с тремя режимами» (F-46). Разбор строки таблицы атаки SHALL следовать соглашению markdown: `\|` — литеральная черта, `\\` — литеральная обратная косая (следующая черта — разделитель), черта внутри backticks — текст ячейки, прочие черты — разделители (журнал `calibration-fixes`: F-23.A, F-45.E, F-46.E).

#### Scenario: Черта в backticks в последней ячейке
- **GIVEN** строка атаки, где черта внутри backticks стоит в последней ячейке «Опора»
- **WHEN** выполняется `render-html … --attack`
- **THEN** строка разобрана в 7 ячеек, код 0, черта показана в ячейке текстом

### Requirement: Негодная строка таблицы атаки — ошибка с местом
Часть требования «Просмотрщик — один HTML из своего шаблона с тремя режимами» (F-46). Строка таблицы атаки, дающая не 7 ячеек после разбора по соглашению markdown, с незакрытым backtick или с пустой ячейкой там, где правило требует значение, SHALL давать ошибку с именем файла, номером строки и именем столбца, код 2 (журнал `calibration-fixes`: F-23.A, F-45.E, F-46.E).

#### Scenario: Лишняя ячейка
- **GIVEN** `attack/decisions.md`, строка таблицы которого после разбора по соглашению markdown даёт 8 ячеек
- **WHEN** выполняется `render-html … --attack attack/decisions.md`
- **THEN** ошибка называет файл и номер строки, код 2, HTML не пишется

### Requirement: Страница `symphysis.html` работает без соседних файлов
Часть требования «Просмотрщик — один HTML из своего шаблона с тремя режимами» (F-46). Страница SHALL оставаться рабочей без соседних файлов: файл mermaid рядом с ней необязателен (F-39). Страница называется `symphysis.html`, потому что несёт не только журнал (журнал `step-help`: F-35).

#### Scenario: Страница перенесена из проекта
- **GIVEN** `symphysis.html` скопирована в каталог вне проекта, где нет `.symphysis/tools/`
- **WHEN** человек открывает её
- **THEN** схема решения показана текстом, режимы и промпт возврата работают
