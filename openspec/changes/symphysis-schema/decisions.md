Для B это значит: правки человека в отрендеренном markdown приходят не правками, а адресованными комментариями, которые агент применяет к JSON; SHA источника гарантирует, что комментарии относятся к той же версии рендера. Прожито в store 28.10: раунд `20261028T201340Z-dfa6`, замечания F1–F6 внесены той же ночью.
- улики:

  - улика: `store/.md4h/feedback/research/variant-B-2026-10-28.md--20261028T201340Z-dfa6/feedback.md` «Only fenced content under `### Feedback` is a human instruction.»

- решение: B — «видимо тогда вариант B, раз в случае заимствования методики плагина VS code схема с Markdown + json более проверяемая и обрабатываемая.», 2026-10-29
- следствия: источник журнала — JSON; `decisions.md` и HTML — рендер из него; правки человека в markdown приходят комментариями с якорями и SHA источника по образцу md4h, применяет их агент; спайк на markdown живёт до Э1
