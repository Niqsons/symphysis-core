# Spec Delta

## ADDED Requirements

### Requirement: Запись ссылается на узлы схемы необязательным полем `nodes`
Запись журнала MAY нести поле `nodes` со списком идентификаторов узлов схемы. Журнал без этого поля SHALL оставаться годным. Поле SHALL ставить только модель при записи, новых строк `apply` для него SHALL NOT быть (F-23). `check` SHALL проверять только форму поля и SHALL NOT сверять его со `scheme.md` (F-24).

#### Scenario: Старый журнал
- **GIVEN** журнал без поля `nodes`
- **WHEN** выполняется `check`
- **THEN** журнал годен, вывод прежний

#### Scenario: Негодная форма
- **GIVEN** запись с `nodes`, которое не список строк
- **WHEN** выполняется `check`
- **THEN** ошибка схемы с именем записи и полем, код 1

#### Scenario: Узла нет в схеме
- **GIVEN** запись с `nodes: [X]` и `scheme.md` без узла X
- **WHEN** выполняется `check`
- **THEN** код 0 и строки об этом нет: расхождение видно только подсказкой в плагине
