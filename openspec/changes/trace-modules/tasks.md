# Tasks

Основания — [specs](specs), [design.md](design.md), [security.md](security.md) и принятые F-16–F-52. Открытых развилок, меняющих список, нет. Чекбоксы означают реализацию и её проверку; создание этого плана их не закрывает.

Места реализации: новый `trace/trace_modules.py` держит чтение структурных объявлений, обследование дерева и нормализованный результат с происхождением; `trace/trace_graph.py` соединяет этот результат с артефактами, отчётом, снимком и экспортом. Разрешение файлов остаётся в `roots/roots.py`. Новый helper не импортирует сборщик обратно и не получает отдельный CLI. Это размещение работы по F-13, F-17–F-24, F-31, F-37, без смены границ capabilities.

Новые проверки чтения и структуры — в `trace/tests/test_trace_modules.py`; интеграция использует существующие `test_trace_graph.py`, `test_trace_report.py`, `test_trace_snapshot.py`, `test_trace_diagram.py`. Тесты resolver, скиллов, anchors и поставки остаются в своих модулях. Точный синтаксис выбранных объявлений закрепляется одной общей фикстурой и GUIDE в 1.1: автор и читатель не должны независимо придумать разные формы (F-17, F-18, F-34, F-35). Поля исходников и байты для хеширования не становятся переносимыми абсолютными путями или копиями README (F-37, F-46).

Порядок — по номерам групп. Для pytest нужен тестовый Python с pytest-xdist, jsonschema и PyYAML; существующий `-n 12` не отключается. В командах ниже `$tracePython` задаётся в PowerShell как `Join-Path $env:LOCALAPPDATA 'Microsoft/WindowsApps/python3.13.exe'`. При изменении кода сначала воспроизводится исходный провал подходящим тестом, затем проверяется исправление. Изолированные пробы используют временные обезличенные деревья и явную карту `--roots`, без личной карты и правки клиентских repo.
