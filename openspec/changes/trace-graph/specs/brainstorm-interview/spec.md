# Spec Delta

## ADDED Requirements

### Requirement: Запись, снимающая решение, называет снятое
Запись журнала, которая снимает прежнее решение, SHALL называть его в `depends_on`; формат журнала от этого SHALL NOT меняться, а `outcome` снятой записи SHALL NOT переписываться (F-11, F-46).

#### Scenario: Срез снимает исход Specify
- **GIVEN** запись F-12 с исходом Specify и новая развилка, решение которой этот сценарий снимает
- **WHEN** модель заводит новую развилку
- **THEN** `depends_on` новой записи называет F-12, `outcome` у F-12 прежний

#### Scenario: Запись забыла назвать снятое
- **GIVEN** новая запись снимает F-12, а в `depends_on` её не называет
- **WHEN** скрипт графа собирает отчёт
- **THEN** сигнал о F-12 остаётся без подсказки, запись `check` не отвергает
