# Spec Delta

## ADDED Requirements

### Requirement: Сценарий по исходу Specify несёт номер записи
Скиллы `symphysis-edge-probe` и `symphysis-prohibition-probe` SHALL ставить комментарий `<!-- F-NN -->` под заголовком сценария, который появился по исходу Specify записи F-NN (F-45). Запись в предел 500 знаков SHALL NOT считаться: комментарий стоит под заголовком сценария.

#### Scenario: Край с исходом Specify
- **GIVEN** кандидат пробы краёв F-12 с решением Specify
- **WHEN** скилл пишет сценарий на этот край
- **THEN** под заголовком сценария стоит `<!-- F-12 -->`, `openspec validate --strict` проходит

#### Scenario: Запрет с исходом Specify
- **GIVEN** кандидат пробы запретов F-13 с решением Specify
- **WHEN** скилл пишет требование с MUST NOT и его сценарий
- **THEN** под заголовком сценария стоит `<!-- F-13 -->`

#### Scenario: Комментарий доходит до мастер-спеки
- **GIVEN** сценарий с `<!-- F-12 -->` в дельте
- **WHEN** дельта сливается с мастер-спекой
- **THEN** комментарий стоит под тем же заголовком в мастер-спеке
