# Security

Чек-лист канона ИБ по `specs/` изменения `parking-addressee-agent`: шесть пунктов схемы и две строки сверх них. Парковок адресату «ИБ» в журнале нет: проба запретов канона не дала. Канон в журнал не чеканится, он отмечается здесь. Реализации ещё нет: «чем проверено» называет сценарий или тест, который поставит `tasks`; прежние тесты названы по имени.

**Главное.** Изменение меняет значение закрытого списка и номер контракта; новых входов у системы нет. Текст, который приходит снаружи, — строка промпта возврата с адресатом парковки: она проходит через `apply` только при значении из списка `агент | человек | ИБ`, иначе отказ без записи. Новый сигнал `check` печатает номер записи и фиксированные слова. Новый тест читает `docs/repo-contract.md` как данные — число из абзаца, исполнения нет. Сети, путей, прав и бинарных файлов изменение не добавляет. Пунктов, не закрытых требованием, при разборе не нашлось.
