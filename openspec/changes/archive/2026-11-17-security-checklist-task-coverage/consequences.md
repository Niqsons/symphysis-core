# Последствия: security-checklist-task-coverage

**Состав:** ветки отказа, допущения

## Опись

- **Входы шагов security и tasks** (`openspec/schemas/symphysis/schema.yaml`): веток отказа не найдено, искал: `id: security`, `id: tasks`, `Опирайся на specs`, `apply:`. Декларация задаёт раздельные входы двух шагов. Согласование второго файла опирается на чтение актуального артефакта по инструкции шага (F-06.A); готовность по наличию файла разобрана ниже.

- **Готовность артефактов после прерванной записи** — `upstream/openspec/src/core/artifact-graph/state.ts:34` «: isArtifactComplete(artifact.generates, changeDir);»
  - при отказе: если `tasks.md` появился, а обновление `security.md` прервалось, оба артефакта уже могут иметь статус `done`. Проверка готовности не учитывает содержание ссылки
  - допущение: автор сверяет два файла по их содержанию. Иначе незаполненная связь может остаться в плане при переходе к реализации
  - кандидат: F-11; ближайший сценарий: Без ссылки после подготовки задач

- **Повтор именованного шага tasks** — `upstream/openspec/src/core/templates/workflows/continue-change.ts:63` «STOP - write nothing, do NOT rewrite its file»
  - при отказе: явный повтор `continue tasks` останавливается на готовом файле до чтения инструкции и поэтому не завершает прерванное согласование
  - допущение: пользователь может запросить точечное согласование существующих файлов через `update-change`, а автор плана должен отличать этот запрос от создания артефакта
  - кандидат: F-11; ближайший сценарий: Без ссылки после подготовки задач

- **Разбор ссылки на требование в чек-листе** — `trace/trace_graph.py:974` «while (m := _SEC_REQ.search(text, pos)):»
  - при отказе: если оформить номер задачи в обратных кавычках и поставить рядом её название в «ёлочках», граф принимает номер за capability. При отсутствии такого требования получается ложный сигнал
  - допущение: подпись задачи сохраняет номер и название в форме, которая отличается от записи ссылки на требование. Иначе отчёт о чек-листе смешает разные виды ссылок
  - кандидат: F-12; ближайший сценарий: Номер или название задачи изменились
