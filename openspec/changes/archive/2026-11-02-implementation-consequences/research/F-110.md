# F-110 · Два читателя `symphysis.yaml`

## Что есть на машине

Проба 2026-11-01, `import yaml` в каждом интерпретаторе домашней машины разработки, пакеты здесь ставятся по ходу работы. Слово человека «почти наверняка есть» сказано о рабочей машине, там проба не проводилась:

| Команда | Итог |
| --- | --- |
| `python` (3.14) | PyYAML 6.0.3 |
| `py -3.13` | нет пакета |
| `python3` | нет пакета |

Инсталлятор ищет `python`, затем `python3` (`installer/lib/check.js:38`). Команды журнала в этом проекте шли через `py -3.13`. Значит, «пакет есть» зависит от интерпретатора даже на одной машине.

## Как читаются значения

Значение в `edge_probe.enabled`:

| Значение | PyYAML `SafeLoader` | `yaml`, схема `core` | PyYAML `BaseLoader` | `yaml`, схема `failsafe` |
| --- | --- | --- | --- | --- |
| `no` | `false` | `"no"` | `"no"` | `"no"` |
| `off` | `false` | `"off"` | `"off"` | `"off"` |
| `False` | `false` | `false` | `"False"` | `"False"` |
| `"false"` | `"false"` | `"false"` | `"false"` | `"false"` |
| `false` | `false` | `false` | `"false"` | `"false"` |
| `выкл` | `"выкл"` | `"выкл"` | `"выкл"` | `"выкл"` |
| без значения | `null` | `null` | `""` | `""` |

Пустой файл и файл из одних комментариев дают `null` у всех четырёх. Таб в отступе даёт ошибку разбора у всех четырёх. `edge_probe: false` вместо вложенного ключа даёт скаляр вместо словаря у всех четырёх.

## Теги

Проба 2026-11-01, значение `enabled: !!python/object/apply:os.system ['echo ВЗЛОМ']`:

| Читатель | Итог |
| --- | --- |
| PyYAML `BaseLoader` | список `["echo ВЗЛОМ"]`, команда не выполнена |
| PyYAML `SafeLoader` | `ConstructorError` |
| `yaml`, схема `failsafe` | список `["echo ВЗЛОМ"]`, предупреждение `TAG_RESOLVE_FAILED`, команда не выполнена |

## Вывод

С настройками по умолчанию читатели расходятся ровно на значениях края F-51: `edge_probe.enabled: no` в `SafeLoader` молча выключает пробу, а в схеме `core` даёт строку, то есть сигнал и «включено».

Одно поведение на обоих языках дают `BaseLoader` и `failsafe`: все значения приходят текстом, и сравнение идёт с `true` и `false` дословно. Цена этого чтения: `"false"` в кавычках читается как `false`, отличить кавычки можно только разбором узлов.
