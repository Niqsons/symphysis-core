# F-114 · Установка из чистого клона

Проба 2026-11-01, коммит `33e376b`, Windows, PowerShell.

| Шаг | Итог |
| --- | --- |
| состояние клона | `installer/node_modules` и `installer/payload` нет |
| `node installer/bin/symphysis.js --help` на чистом клоне | `ERR_MODULE_NOT_FOUND` |
| `npm --prefix installer ci` | `installer/node_modules` и `installer/payload/skills` появились, `prepare` отработал сам |
| `node installer/bin/symphysis.js --help` после `ci` | справка напечатана |
| `npm i -g ./installer --prefix <временный>` | ссылка-junction на `installer/` клона, `symphysis.cmd` отвечает |

## Вывод

Блокер первой атаки подтверждён запуском, а решение F-114.A работает. Глобальная установка из каталога не копирует файлы, а ставит ссылку в клон, поэтому `git pull` и `npm --prefix installer ci` обновляют и команду `symphysis`. Откат — `npm rm -g @niqsons/symphysis`. Удаление клона ломает команду.
