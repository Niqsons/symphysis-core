# F-133 · Контекст прогонов

## Что видели прежние плечи

Транскрипты `c3-p1`, `c3-p2`, `c3-p2-cf`, `c3-v1-fable`. Каждое плечо, и ваниль тоже, получало контекст человека:

| Что | Есть в каждом плече |
| --- | --- |
| глобальный `CLAUDE.md` человека | да |
| хук `superpowers` при старте | да |
| списки скиллов плагинов | да |
| MCP человека | да |
| стиль Explanatory, блоки Insight в ответах | да, 8–17 блоков на сессию |
| файлы автопамяти человека | нет |

Чужих скиллов и агентов плечи при этом не вызывали: инструмент Skill звал только `symphysis-*`, у ванили `openspec-explore` и `opsx:explore`; инструмента Agent нет ни в одном плече.

Аудит путей показал две вылазки за пределы проекта: `Glob` в `C:\Users\User\.m2` у `c3-p2-cf` и в `C:\Users\User\.claude` у `c3-v1-fable`. Прочие строки аудита — упоминания пути из материалов задачи.

## Проба чистоты

Модель `claude-haiku-5-5`, пустой проект со своим скиллом и своей командой, вход по подписке:

| Вариант | Вход, токенов | Плагины | Скиллы | Маркеры чужого контекста |
| --- | --- | --- | --- | --- |
| как прежний водитель | 52 924 | 10 | 96 | все |
| `--setting-sources project --strict-mcp-config`, без родительского окружения | 23 849 | 3 встроенных | 21 | `CLAUDE.md` человека |
| то же и `CLAUDE_CODE_DISABLE_CLAUDE_MDS=1`, `CLAUDE_CODE_DISABLE_AUTO_MEMORY=1` | 22 544 | 3 встроенных | 21 | нет |

`--bare` не подходит: он читает только ключ API, вход по подписке не работает.

## Вывод

В каждом запросе прежних прогонов было около 30 тысяч токенов чужого контекста, у всех плеч одинаково. Числа тех прогонов с новыми напрямую не сравниваются, а сравнение плеч внутри прежней серии остаётся сравнением в одних условиях. Чистый контекст проверяется на первом ходу по транскрипту, и находка останавливает прогон.
