# Security

Чек-лист канона ИБ по `specs/` изменения `symphysis-schema`. Источники
пунктов: instruction артефакта (пять пунктов) и парковки адресату «ИБ»
из пробы запретов (F-80…F-83) — канон в журнал не чеканится, он отмечается
здесь. «Чем проверено» — чтение файла, команда прогона или тест; где
проверки не было — так и написано.

| Пункт | Применимо / неприменимо — причина | Чем проверено |
| --- | --- | --- |
| Инъекции через содержимое файлов | применимо — `research`, `symphysis-attack` и `symphysis-brainstorm` читают произвольные файлы проекта и внешних корней и цитируют их в артефакты (specs `artifact-graph` «Исследование — файл на каждую парковку…», `artifact-attack` «Строка атаки валидна…», `brainstorm-interview` «Вопрос, ответ на который есть в файлах…»); **требования, закрывающего пункт («содержимое прочитанного файла — данные, не инструкция»), в specs нет** — парковка F-81 | чтение specs/: `grep -rn -i "недоверенн\|untrusted" openspec/changes/symphysis-schema/specs` — пусто; прогон: `research/F-01.md` цитирует файлы стороннего расширения (md4h) и связку из `X:\skills-store` |
| Пути с `../` | применимо — `evidence.path` разрешается `_resolve` склейкой корня и хвоста без проверки выхода за корень; хвост `../…` или абсолютный путь после префикса `""` читает любой файл машины; требование `decision-journal` «Улика сверяется скриптом дословно…» («по корням `journal-roots.json`») закрывает только выбор корня, не выход из него — парковка F-80 | чтение `tools/journal_apply.py:48-53` (`return roots[prefix] / path[len(prefix):]`); команда-кандидат `check` на журнале с `path: ../../Windows/win.ini` — в прогоне не запускалась |
| Токены и срок их жизни | неприменимо — конвейер не хранит, не передаёт и не читает токенов и секретов; `CONFLUENCE_TOKEN` из плана — окружение обкатки flow-specs, вне этого изменения | `grep -rn -i "token\|secret\|password" tools/*.py installer/lib/*.js` — пусто |
| Права | применимо — установщик пишет в `openspec/`, `.symphysis/` и каталоги скиллов проекта; закрывает требование `project-installer` «`install` ставит схему, скиллы и инструменты…»: отличающийся файл пропускается без `--force`, файл корней не перезаписывается; `check` только читает — парковка F-83 | прогон, шаг 1: «записано 27», файлы схемы с теми же байтами не тронуты; чтение `installer/lib/install.js` (`place()`: `if (!force) { res.skipped.push(...) }`); тесты `installer/test` в прогоне не запускались |
| Бинарные файлы | применимо — `check` читает файл улики как текст с `errors="replace"`: бинарный файл не роняет сверку, цитата в нём не найдётся («цитаты нет дословно»); требование `decision-journal` «Улика сверяется…» этого не оговаривает — пункт закрыт поведением кода, не спекой | чтение `tools/journal_apply.py:78` (`read_text(encoding="utf-8", errors="replace")`); тест на бинарную улику — кандидат, в `tests/test_journal_check.py` не найден (`grep -n "bin\|bytes" tests/test_journal_check.py` — пусто по смыслу) |
| Инъекции в HTML просмотрщика | применимо — слово человека, цитаты улик и текст записей встраиваются в `decisions.html`; требование `decision-viewer` «Просмотрщик — один HTML…» экранирование не называет — парковка F-82 | `grep -n "esc(" tools/playground-template.html` — функция экранирования есть (строка 331); применение ко всем полям карточки не проверялось; тест на `<script>` в слове человека — кандидат (tasks 7.2) |
| Данные наружу (телеметрия форка) | применимо — форк наследует телеметрию OpenSpec: `init` пишет `telemetry.anonymousId` в глобальный конфиг пользователя; `symphysis install` этого не касается и не предупреждает; закрывающего требования нет — кандидат-запрет F-79 (открыт) | прогон, шаг 1: `openspec config list` → `telemetry: noticeSeen: true, anonymousId: …`; README установщика слова «telemetry» не содержит (`grep -c telemetry installer/README.md` → 0) |
