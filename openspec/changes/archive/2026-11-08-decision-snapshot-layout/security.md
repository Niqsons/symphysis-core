# Security

| Пункт | Применимо / неприменимо — причина | Чем проверено |
| --- | --- | --- |
| Инъекции через содержимое файлов | Применимо — общая карточка, улики и `notes[]` вставляют содержимое журнала в HTML; действуют требования «Текст журнала и атаки экранируется в HTML» и «Подписи схемы не ходят в сеть» | Сценарии «Скрипт в слове человека», «Backticks как единственная разметка», «Картинка с внешним адресом»; тест `test_viewer_escapes_journal_and_attack_text_in_every_mode` |
| Пути с `../` | Применимо — обе раскладки показывают ссылки улик и редактора; требование «Файлы на странице показаны ссылками» разрешает адреса только из карты файлов внутри корней улик и каталога изменения, текст журнала адресом не становится | Сценарии «Файла нет», «Ссылка внутри варианта», «Негодная маска» |
| Токены и срок их жизни | Неприменимо — изменение не использует авторизацию, токены или сетевые API; страница работает с локальными встроенными данными | Требование «Страница не ходит в сеть» и сценарий «Журнал сети браузера»; чтение `viewer/playground-template.html` не нашло обращения к токенам |
| Права | Применимо — «снимок» не должен давать редактировать черновик или писать на диск; действуют требования «Раскладка «снимок» только для чтения» и «Просмотрщик — один HTML из своего шаблона» | Сценарии «Ввод недоступен в снимке», «Черновик сохраняется при смене раскладки», «Скрытые органы не меняют черновик» |
| Бинарные файлы | Применимо — улика может указывать на бинарный файл; его содержимое не разбирается как текст, ссылка остаётся, а несверенная цитата не становится «не найдено» | Требования «Все варианты и рекомендация показаны целиком» и «Файлы на странице показаны ссылками»; тест `test_viewer_unchecked_evidence_is_neutral_not_missing` |
| Чувствительные данные в журнале, артефактах и журналах прогона | Применимо — страница встраивает журнал, заметки и справку локально; сеть запрещена, а справка не несёт абсолютных путей | Требования «Страница не ходит в сеть», «Подписи схемы не ходят в сеть», «Снимок справки не несёт абсолютных путей»; сценарии «Журнал сети браузера», «Каталог с заметным именем», «Причина сбоя без каталога» |
