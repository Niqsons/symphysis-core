# Security

Чек-лист для `scenario-run-change-impact`. Проверка на этом шаге опирается на требования и сценарии. Поведение ядра и форка предстоит проверить при реализации.

| Пункт | Применимо / неприменимо — причина | Чем проверено |
| --- | --- | --- |
| Инъекции через содержимое файлов | Применимо — [«Scenario-run устанавливает область влияния изменения»](specs/artifact-attack/spec.md) задаёт чтение сценариев и их источников как данных. [«Изменившаяся мастер-опора видна в состоянии вердикта»](specs/verdict-readiness/spec.md) удерживает `stale` при некорректном объявлении опоры, даже если локальные цели совпали. | Сценарии «Текст мастер-сценария пытается изменить ход проверки» и «Объявленная мастер-опора не разбирается». |
| Пути с `../` | Применимо — [«Состав устаревания называет изменившуюся мастер-опору»](specs/stale-verdict-scope/spec.md) ограничивает чтение каталогом мастер-спек выбранного корня после разрешения ссылок и отклоняет абсолютные имена и компоненты `..` до чтения. [«Граф связывает задачу со сценарием вне дельты»](specs/trace-graph/spec.md) сохраняет ту же область чтения. | Сценарии «Мастер-опора выходит из области чтения» и «Файл мастер-сценария находится за границей мастер-спек». При реализации сценарии со ссылками покрывают также junction на Windows. |
| Токены и срок их жизни | Неприменимо — сверка читает локальные файлы и вычисляет отпечатки SHA-256. Изменение не вводит сетевых запросов, учётных данных или сессий. | Чтение [design.md](design.md) и четырёх дельт. |
| Права | Применимо — область чтения задаёт [«Состав устаревания называет изменившуюся мастер-опору»](specs/stale-verdict-scope/spec.md). [«Изменившаяся мастер-опора видна в состоянии вердикта»](specs/verdict-readiness/spec.md) сохраняет контроль допуска к `apply`, когда система отказала в чтении разрешённого файла. | Сценарии «Мастер-опора выходит из области чтения», «Использованная мастер-опора существует, но файл не читается» и оба сценария окна допуска к `apply`. |
| Бинарные файлы | Применимо — по [«Изменившаяся мастер-опора видна в состоянии вердикта»](specs/verdict-readiness/spec.md) содержимое вне UTF-8 даёт `stale` и согласованную причину у читателей. | Сценарий «Объявленная мастер-опора не разбирается», случай содержимого вне UTF-8. |
| Чувствительные данные в журнале, артефактах и журналах прогона | Применимо — [«Изменение мастер-опоры обесценивает вердикт»](specs/artifact-attack/spec.md) ограничивает новые метаданные отчёта идентификаторами и отпечатками. [«Состав устаревания называет изменившуюся мастер-опору»](specs/stale-verdict-scope/spec.md) ограничивает новый диагностический вывод проверенным относительным местом или номером записи. | Чтение требований и сценариев «Мастер-опора выходит из области чтения» и «Объявленная мастер-опора не разбирается». |
