# Spec Delta

## ADDED Requirements

### Requirement: Изменившаяся мастер-опора видна в состоянии вердикта
Для вызванной атаки артефактов с `status: passed` изменение, утрата, ошибка чтения или некорректное объявление использованной мастер-опоры SHALL давать `verdict: stale`. Для `apply` SHALL действовать обычное окно устаревания. Отчёт без поля мастер-опор проверяется по объявленным целям (F-10.A, F-12.A, F-15.A).

#### Scenario: Мастер-опора изменилась до реализации
- **GIVEN** вызванная атака артефактов прошла, использованный мастер-блок изменился, цели атаки совпадают и отмеченных задач нет
- **WHEN** OpenSpec проверяет статус изменения и допуск к `apply`
- **THEN** статус показывает `verdict: stale` и `apply` заблокирован этим вердиктом

#### Scenario: Мастер-опора изменилась после первой задачи
- **GIVEN** вызванная атака артефактов прошла, использованный мастер-блок изменился, цели атаки совпадают и одна задача уже отмечена
- **WHEN** OpenSpec проверяет статус изменения и допуск к `apply`
- **THEN** статус показывает `verdict: stale` как сигнал, и этот вердикт считается удовлетворённым для `apply`

#### Scenario: Старый отчёт проверяется по своим целям
- **GIVEN** сохранившийся отчёт атаки с `status: passed` записан в старом формате без сведений о мастер-опоре, все объявленные цели совпадают
- **WHEN** OpenSpec проверяет статус этого изменения
- **THEN** отчёт получает `verdict: ok`

#### Scenario: Объявленная мастер-опора не разбирается
- **GIVEN** отчёт с `status: passed` и совпадающими локальными целями содержит неразбираемое поле мастер-опор, неоднозначный идентификатор или опору с содержимым вне UTF-8
- **WHEN** OpenSpec, `journal check` и справка шага проверяют свежесть отчёта
- **THEN** OpenSpec показывает `verdict: stale`, журнал и справка дают одну причину без копирования некорректного содержимого

#### Scenario: Использованная мастер-опора существует, но файл не читается
<!-- F-12 -->
- **GIVEN** отчёт атаки с `status: passed` называет использованную мастер-опору, локальные цели совпадают, файл опоры существует, но чтение завершается ошибкой
- **WHEN** OpenSpec, `journal check` и справка шага проверяют свежесть отчёта
- **THEN** OpenSpec показывает `verdict: stale` с действующим окном допуска к `apply`, а `journal check` и справка завершают сверку с диагностикой, называющей одну и ту же нечитаемую опору
