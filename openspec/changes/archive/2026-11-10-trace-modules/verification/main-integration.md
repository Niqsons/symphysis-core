2026-11-10. Владелец разрешил вливание и разрешение конфликтов: «Можно вливать. Конфликты разрешай по ходу. Main Обновился с тех пор как было сделано обновление, возможно проще будет сначала влить его в worktree.»

Ветка изменения перед интеграцией — `feat/trace-modules`, `549302a4`. В неё включён main `9598732f` коммитом `8b1909b2`. Затем учтены новые коммиты main до `a520e135`, обновляющие поставку OpenSpec до `1.16.1+symphysis.6`.

## Разрешение конфликтов

- `anchor_refs.py`: сохранены защита JSON-аннотации реализации и новая защита унаследованных комментариев/базы B-45.
- Brainstorm/research: сохранён preflight и доступ к ресурсам выбранного runtime из main; общий протокол модулей читается через `symphysis resource doc module-declarations.md`. В самом протоколе сборка вызывается через `symphysis trace build` с теми же селекторами проекта/store. На оставшийся старый локальный вызов получен RED, затем GREEN нового утверждения теста.
- Installer: сохранён managed installer main, без возвращения прежней функции установки. Общий inventory payload переносит `trace_modules.py`; check и его тест знают одновременно `trace_modules.py`, `runtime_context.py`, `sync_check.py`.
- Правила specs и тесты: объединены сохранение аннотации реализации и происхождения унаследованных ссылок. В master trace-conventions сохранены обе группы новых требований.
- Research instruction осталась в прежнем пределе 150 слов; YAML сохранён с LF для проверки порядка артефактов. Тесты и числовые пределы не ослаблялись.
- К действительным зависимостям trace добавлен runtime. Устранена лишняя пустая строка EOF в пришедшем из main runtime-contract.md; смысл документа не изменён.

Независимый reviewer проверил девять конфликтов, точечный автомерж trace_graph/roots и последующее исправление рецепта. Существенных замечаний после исправления не осталось. Полные проверки, последующие коммиты с `.6` и native smoke reviewer не выдавал за проверенные им.

## Настоящие local/global установки

Размер payload тел после объединения: brainstorm — 2942 слова, research — 2457. Числовой ориентир 1500 превышен у исходных многошаговых тел; поведение ради числа не удалялось, общий протокол остался отдельным ресурсом.

[runtime-integration-probe.py](runtime-integration-probe.py) устанавливает актуальный payload локальным installer/bin в два изолированных временных профиля. Используются настоящий форк и Python 3.13.14. Изоляция профиля скрывает пользовательские site-packages; уже установленный тестовый PyYAML передаётся через PYTHONPATH, без загрузки пакетов и изменения реального профиля. Без него первая проба честно получила сигнал отсутствия PyYAML; это было свойство окружения стенда, не молчаливое отсутствие модулей.

В обоих scope прошли preflight, загрузка общего протокола через resource, build/freeze/check через runtime CLI. Граф содержит модуль core/viewer и implements к требованию. README неизменен, check не дал сигналов. В global store локального trace_graph.py нет, helper находится в пользовательском runtime. Содержимое загруженного общего протокола совпало между local/global по SHA-256. [Результаты](runtime-integration-results.json), [вывод](runtime-integration-output.txt).

Это проверка native CLI и доступности нового общего ресурса, не новый прогон модельного интервью. Модельные пробы исходной реализации и их пределы остаются в repository-survey.md.

## Итоговые проверки

Первые полные прогоны промежуточного состава остановлены после появления новых коммитов main с поставкой `.6`; их незавершённый результат не заявляется пройденным. Полные команды запущены заново для итогового состава. Pytest сам содержит оболочку полного `node --test`; отдельный `npm --prefix installer test` проверяет также штатный pretest.

Одновременный запуск полного pytest и отдельного npm породил два Node-набора и исчерпал место на C: ошибки ENOSPC и тайм-ауты не считаются успешной проверкой. Полный Python-прогон дал 2136 passed, 4 skipped и одно падение оболочки Node. Её повтор на новом временном корне `X:\symphysis-trace-modules-verify-549302a4` прошёл: **1 passed за 307,18 с**, с сохранённым xdist и прежними тайм-аутами тестов. В итоге проверены все 2137 успешных тестов набора; это полный прогон с повтором единственной упавшей проверки, не заявление об одном непрерывном зелёном запуске. [Результат повторной проверки](installer-retry-x.txt).

Пропуски: отсутствующий внешний md4h root прежних улик, пустой набор параметров одного corpus-теста journal validator и два прежних живых теста уже заархивированного trace-graph. Интеграция с настоящим форком и Node-набор не пропущены. Удалены 70 только наших временных каталогов без reparse-точек, опознанных по manifest bootstrap данного worktree и времени создания; освобождено около 0,73 ГБ. Каталоги других сессий и реальные пользовательские установки не изменялись.

`openspec validate --specs --json`: **37/37, код 0**. Гейт имён и git diff --check прошли; обычные предупреждения о локальных путях в документах контура разработки не являются новыми переносимыми полями продукта.

Сохранённые ранее graph/req-graph.json, graph/report.md, decisions.json и consequences.md не изменялись интеграцией: их содержимое совпадает с `549302a4`. Архивный снимок не пересобирался из нынешнего дерева.
