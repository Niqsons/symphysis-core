# Security

Чек-лист канона ИБ по `specs/` изменения `attack-warning-read`: шесть пунктов схемы, парковка адресату «ИБ» у F-14 (экранирование текста раздела на странице) и две строки сверх канона схемы. Канон в журнал не чеканится, он отмечается здесь. Реализации ещё нет: «чем проверено» называет сценарий или тест, который поставит `tasks`; прежние тесты названы по имени.

**Главное.** Новых поверхностей две. Первая — круговорот текста: раздел строки атаки уходит в промпт возврата, через `apply` ложится заметкой в `notes[]` и возвращается на страницу, где сверяется со строками и показывается флагом; весь текст — строки, которые страница вставляет через `esc` и `md`, а сверяет сравнением после схлопывания пробелов. Вторая — чтение заметок скиллом атаки ради пометки «(прочитано)»: текст заметки для него данные. Сети, новых файлов, путей и прав изменение не добавляет. Пунктов, не закрытых требованием, при разборе не нашлось.
