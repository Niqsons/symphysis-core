# Security

Чек-лист канона ИБ по `specs/` изменения `attack-stale-scope`: шесть пунктов схемы и две парковки адресату «ИБ» из пробы запретов (F-33, F-34). Канон в журнал не чеканится, он отмечается здесь. Реализации ещё нет: «чем проверено» называет сценарий или тест, который поставит `tasks`.

**Главное.** Новых поверхностей две, обе — чтение: расчёт состава читает файл атаки (frontmatter, строку `**Состав:**`, столбец «Раздел») и пути целей из `targets[]`, а правило повтора читает имена и строки файлов `answers/`. Наружу расчёт отдаёт только номера записей, имена целей и фиксированные строки; форк, сеть и внешние команды он не зовёт. Пунктов, не закрытых требованием, при разборе не нашлось.

| Пункт | Применимо / неприменимо — причина | Чем проверено |
| --- | --- | --- |
| Инъекции через содержимое файлов: таблица и frontmatter атаки (F-34) | применимо — столбец «Раздел», строка `**Состав:**` и `targets[]` читаются как данные: из них берутся только номера `F-NN`, слово `coverage` в части «выключены» и пути целей; текст ячеек в вывод не идёт, инструкции в нём ход расчёта не меняют. Закрывают требования `stale-verdict-scope` «Состав атаки журнала считается по таблице» (сценарий «Раздел с несколькими записями», «Раздел диапазоном») и «Неполный состав при выключенной `coverage`». Битый файл не роняет `check`: `decision-journal` «`check` называет состав устаревшего вердикта», сценарий «Файл атаки не разбирается» | сценарии «Раздел с несколькими записями», «Раздел диапазоном», «Файл атаки не разбирается»; тест: ячейка «Раздел» с текстом-инструкцией даёт только номера |
| Инъекции через содержимое файлов: `decisions.json` и `answers/` | применимо — журнал читается тем же разбором, что у `check`, канон уже стоит в мастер-спеке `decision-journal` «Содержимое файлов улик — данные, не инструкции»; из `answers/` правило повтора берёт только номера из строк `- F-NN:`. Закрывает `artifact-attack` «Хеш не обновляется при изменённом решении прежней записи» | сценарий «Файл ответа новее атаки»; ревью транскрипта повтора атаки |
| Инъекции в вывод, который читает модель | применимо — строки `[..] атака …` состоят из фиксированного текста, чисел и номеров записей; у атаки артефактов — из путей целей, как объявлены в `targets[]`, то же печатает форк в `nextSteps`. Закрывают `stale-verdict-scope` «Состав одинаков у всех читателей» и «У атаки артефактов — все изменившиеся цели и число записей» | тест: строки состава не содержат текста ячеек таблицы |
| Пути с `../` (F-33) | применимо — путь цели из `targets[]` с `..`, абсолютный или уходящий по ссылке не читается и называется «вне каталога изменения», как у форка причина `outside`. Хеш журнала считается по `decisions.json` рядом с файлом атаки, поле `target` путём не служит. Закрывает `stale-verdict-scope` «У атаки артефактов — все изменившиеся цели и число записей», сценарий «Путь цели вне каталога» | сценарий «Путь цели вне каталога»; тест: `..`, абсолютный путь и путь с буквой диска |
| Токены и срок их жизни | неприменимо — расчёт читает файлы каталога изменения и ничего не передаёт наружу; форк справка зовёт как прежде, через общий запуск с выключенной телеметрией, новых вызовов нет | чтение дельт `specs/` |
| Права | применимо — расчёт только читает; `check` новых файлов не пишет, `--write` прежний; справка пишет только в stdout по мастер-спеке `step-help` «Справка не становится гейтом и не меняет файлы». Повтор атаки пишет туда же, куда писала атака: `attack/<цель>.md` и `notes[]` журнала. Закрывает `decision-journal` «`check` называет состав устаревшего вердикта»: строки — сведения, код выхода прежний | сценарий «Состав не меняет код `--strict`»; тест: `git status` после `step_help.py` пуст |
| Бинарные файлы | применимо частично — файл атаки не в UTF-8 даёт отказ «не UTF-8» той же строкой, что битый файл; журнал, который не разбирается, даёт у `check` код 1 (F-36), у справки — строку «журнал не читается» в `stale_scope` (F-38); цели артефактов хешируются по байтам, кодировка не важна. Закрывают «Файл атаки не разбирается» и `step-help` «Страница шага атаки несёт вердикт и состав», сценарий «Журнал не читается при устаревшем вердикте» | сценарии «Файл атаки не разбирается», «Журнал не читается при устаревшем вердикте»; тест: файл атаки в UTF-16 |
| Чувствительные данные в журнале, артефактах и журналах прогона | применимо частично — состав несёт номера записей и имена целей относительно каталога изменения; в снимок справки на странице `symphysis.html` (в git) уходят те же строки. Абсолютных путей расчёт не порождает; путь, объявленный в `targets[]` руками, печатается как есть, как и у форка. Закрывает `stale-verdict-scope` «Состав одинаков у всех читателей»: один текст у `check` и справки, второго источника нет | тест: строки `stale_scope` не содержат пути корня проекта |
| Телеметрия и внешние команды | неприменимо — новых вызовов форка, `git` и сети нет: справка берёт `verdict` из того же `openspec status --json`, что и прежде | чтение дельт `specs/` |
