# Spec Delta

## ADDED Requirements

### Requirement: README модулей описывают зависимости для отбора тестов
README модулей ядра и VS Code SHALL объявлять в `dependencies` зависимости, по которым отбор тестов находит их потребителей. Зависимость SHALL указывать репозиторий и имя модуля из его декларации (F-08).

#### Scenario: Зависимость от модуля с отличающимся именем каталога
- **GIVEN** имя объявленного модуля отличается от имени его каталога
- **WHEN** другой модуль объявляет зависимость от него для отбора тестов
- **THEN** зависимость указывает репозиторий и объявленное имя модуля

#### Scenario: Новый потребитель существующего модуля
- **GIVEN** модуль начал использовать другой модуль, от которого зависит результат его тестов
- **WHEN** проверяется состав деклараций для отбора тестов
- **THEN** README потребителя содержит связь с этим модулем
