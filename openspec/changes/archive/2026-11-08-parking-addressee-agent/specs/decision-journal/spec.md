# Spec Delta

## MODIFIED Requirements

### Requirement: Обратимость, адресат парковки и исход — из закрытых списков с причиной
У решённой записи SHALL быть `reversibility.level` из `обратимо | дорого | в одну сторону` с непустым `why`; у записи пробы (с `outcome`) `reversibility` не требуется; `outcome` пробы SHALL быть из `Specify | Dismiss | Backstop | Defer`; `parking[].addressee` SHALL быть из `агент | человек | ИБ`, `addressee` записи — из `агент | человек | ИБ | постановка | ""`; нарушение SHALL давать код 1 у `check` (журнал `symphysis-schema`: F-10.A, F-09.C, F-11.D; F-01, F-03, F-06, F-17).

#### Scenario: Рекомендованный отказ без слова
- **GIVEN** запись пробы с `outcome: {kind: проба, value: Dismiss, reason: ""}`, решение совпадает с рекомендацией
- **WHEN** выполняется `check`
- **THEN** код 0, строки `[!!]` об этой записи нет

#### Scenario: Выбор мимо рекомендации без слова
- **GIVEN** решение B при рекомендации A, слова нет
- **WHEN** выполняется `check`
- **THEN** stdout несёт `[!!] <F-NN>: выбран не рекомендованный вариант B без слова`, код 0, с `--strict` — 2

#### Scenario: Вариант, добавленный человеком
- **GIVEN** решение по варианту с `added: true`, слова нет
- **WHEN** выполняется `check`
- **THEN** строки `[!!]` об этой записи нет

#### Scenario: Адресат вне списка
- **GIVEN** парковка с `addressee: архитектор`
- **WHEN** выполняется `check`
- **THEN** ошибка схемы с именем записи и полем `parking/0/addressee`, код 1

#### Scenario: Факт постановки
- **GIVEN** запись `kind: факт`, `addressee: постановка` с уликой `path: openspec/changes/<имя>/intent.md`
- **WHEN** выполняется `check`
- **THEN** журнал годен (код 0); журналы плеч без значения `постановка` остаются годными

#### Scenario: Факт без улики
- **GIVEN** запись `kind: факт` с пустым `evidence[]`, без парковки, `status: решён`
- **WHEN** выполняется `check`
- **THEN** строка `[!!] <F-NN>: факт без улики`, код 1

#### Scenario: Припаркованный факт без улики
- **GIVEN** запись `kind: факт`, `status: припаркован`, `evidence: []` с парковкой `addressee: агент`
- **WHEN** выполняется `check`
- **THEN** строки «факт без улики» нет, код 0

#### Scenario: Пустое why
- **GIVEN** развилка с `recommendation.why: ""`
- **WHEN** выполняется `check`
- **THEN** строка `[!!] <F-NN>: рекомендация без why`, код 1

#### Scenario: Парковка без находки при файле
- **GIVEN** парковка `addressee: агент` без `finding` и существующий `research/F-NN.md`
- **WHEN** выполняется `check`
- **THEN** строка `[!!] <F-NN>: парковка «агент» без finding при research/F-NN.md`, код 0; с `--strict` — код 2

## ADDED Requirements

### Requirement: Старое значение адресата читается, новыми записями не пишется
Часть требования «Обратимость, адресат парковки и исход — из закрытых списков с причиной» (F-20). Значение `материалы` у `parking[].addressee` и у `addressee` записи SHALL приниматься `check` только как значение старых журналов — годен, каждое вхождение сигналит строкой `[!!]` (F-22); сравнение точное, без нормализации (журнал `calibration-fixes`: F-36 Dismiss). Строку `припарковано → материалы — «…»` `apply` SHALL отвергать кодом 1 с перечнем `агент | человек | ИБ` (F-17, F-11, F-07).

#### Scenario: Старый журнал годен
- **GIVEN** архивный `decisions.json` с `addressee: материалы` у парковки и у записи
- **WHEN** выполняется `check`
- **THEN** код 0; строка `[!!]` о старом значении — сигнал, не ошибка схемы

#### Scenario: Строка apply со старым значением
- **GIVEN** файл ответа со строкой `- F-01: припарковано → материалы — «вопрос»`
- **WHEN** выполняется `apply`
- **THEN** отказ `F-01: адресат «материалы» — допустимы агент | человек | ИБ`, код 1, журнал не изменён

#### Scenario: Старое значение в журнале активного изменения
<!-- F-22 -->
- **GIVEN** журнал активного изменения с парковкой `addressee: материалы`, записанной в JSON мимо `apply`
- **WHEN** выполняется `check`
- **THEN** строка `[!!] F-NN: адресат «материалы» — старое значение, новые записи пишут «агент»`, код 0; с `--strict` — код 2

### Requirement: Просмотрщик и рендер при двух значениях адресата
Часть требования «Обратимость, адресат парковки и исход — из закрытых списков с причиной» (F-20). Просмотрщик SHALL предлагать для парковки только `агент | человек | ИБ`; рендер и страница SHALL вести парковки `агент` и парковки `материалы` старых журналов в одно назначение `research/` (F-02, F-08, F-17).

- **WHEN** выполняется `render-md`
- **THEN** у парковки назначение `design.md › Open Questions → research/`, как у парковки `агент`

### Requirement: Слово к решению мимо рекомендации
Часть требования «Обратимость, адресат парковки и исход — из закрытых списков с причиной» (F-20). Решение мимо рекомендации без слова `check` SHALL сигналить строкой `[!!]` (код 0, с `--strict` — 2): слово объясняет читателю журнала, почему выбор разошёлся с рекомендацией; рекомендованному варианту и варианту, добавленному человеком, слово SHALL NOT требоваться (слово человека, журнал `step-help`).

#### Scenario: Слово к выбору мимо рекомендации внесено
- **GIVEN** решение B при рекомендации A со словом «так короче»
- **WHEN** выполняется `check --strict`
- **THEN** строки `[!!]` об этой записи нет, код 0

### Requirement: Пометка отступления стоит у варианта
Часть требования «Обратимость, адресат парковки и исход — из закрытых списков с причиной» (F-20). Факты из `intent.md` несут `addressee: постановка` (журнал `calibration-fixes`: F-17.A). Развилка, чей вариант меняет факт `постановка`, SHALL нести пометку «отступление от постановки» со ссылкой на факт: пометка — поле `deviation` у варианта (`options[].deviation`) (журнал `calibration-fixes`: F-08.A, F-62.A, F-28.E).

#### Scenario: Пометка у отступающего варианта
- **GIVEN** развилка, вариант D которой несёт `deviation: F-03`, и факт `F-03` с `addressee: постановка`
- **WHEN** выполняется `check`
- **THEN** код 0, пометка стоит у варианта D, у вариантов A–C поля нет

### Requirement: `check` отвергает факт без улики и пустую причину, парковку без находки сигналит
Часть требования «Обратимость, адресат парковки и исход — из закрытых списков с причиной» (F-20). `check` SHALL отвергать кодом 1 факт без улики (если у записи нет парковки и статус не `припаркован`) и `recommendation` с пустым `why`; парковку «агент» без `finding` при существующем `research/<F-NN>.md` SHALL сигналить строкой `[!!]` (код 0, с `--strict` — 2) (журнал `calibration-fixes`: F-12.A, F-35.E; F-08; предположение: сигнал, не ошибка — состояние законно до второго круга; решить).

### Requirement: Адресат `агент` означает агента исследования
Адресат `агент` MUST NOT читаться как любой агент с моделью — плагин, хук, главная нить чата: глоссарий `terms.md` SHALL определять его как водителя шага `research`, подсказка страницы SHALL называть его агентом исследования; проверяют тесты текстов — `tests/test_skills.py` по строке глоссария и `viewer/tests/test_viewer_page.py` по строке шаблона (F-25).
