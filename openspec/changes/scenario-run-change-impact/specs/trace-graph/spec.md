# Spec Delta

## ADDED Requirements

### Requirement: Граф связывает задачу со сценарием вне дельты
Граф SHALL разрешать ссылку задачи по указанной capability сначала в дельте, затем среди сценариев, которые остаются в мастере после применения дельты. Для найденного только в мастере сценария граф SHALL дать связь `satisfies` с местом в задаче и обозначить место сценария в мастере. Включаются только названные мастер-сценарии и их контекст (F-05, F-06.A, F-08.A).

#### Scenario: Единственная ссылка на сценарий мастера
- **GIVEN** задача называет сценарий с capability, в дельте такого имени нет, а в указанной мастер-спеке есть этот сценарий и соседний неназванный сценарий
- **WHEN** скрипт собирает граф
- **THEN** есть связь `satisfies` с местом ссылки в задаче и указанием места сценария в мастере, соседний сценарий не включён и эта ссылка не получает сигнал «неизвестное имя или номер»

#### Scenario: Дельта содержит тот же сценарий
- **GIVEN** задача называет сценарий, который в указанной capability встречается один раз в дельте и один раз в мастере
- **WHEN** скрипт собирает граф
- **THEN** связь ведёт к сценарию дельты, отдельного узла для одноимённой версии мастера нет

#### Scenario: Одноимённые сценарии в мастере
- **GIVEN** в дельте указанной capability нет такого сценария, а в мастере у двух разных требований есть сценарий с названным в задаче именем
- **WHEN** скрипт собирает граф
- **THEN** есть связи к обоим кандидатам и сигнал «неоднозначное имя», называющий оба требования

#### Scenario: Сценарий исчезает после применения дельты
- **GIVEN** задача называет единственный сценарий с таким именем в capability, а дельта удаляет его требование или заменяет его версией без этого сценария
- **WHEN** скрипт собирает граф
- **THEN** старая версия сценария не разрешает ссылку, отчёт называет неразрешённую ссылку

#### Scenario: Такое имя есть только в другой capability
- **GIVEN** задача называет сценарий с capability, в которой он отсутствует, и в другой capability есть это имя
- **WHEN** скрипт собирает граф
- **THEN** отчёт называет неразрешённую ссылку для указанной capability, ребра к сценарию другой capability нет
