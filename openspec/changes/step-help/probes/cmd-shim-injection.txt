Маркер: файл, который создаёт команда из аргумента, если cmd.exe её исполнил.
'demo' -> код 0 | маркер создан: False
'a&echo.>INJECTED.txt' -> код 0 | маркер создан: True
'a|echo.>INJECTED.txt' -> код 0 | маркер создан: True
'a&echo INJECTED>INJECTED.txt' -> код 0 | маркер создан: False
'a"&echo INJECTED>INJECTED.txt' -> код 0 | маркер создан: True
'..\\..\\x' -> код 0 | маркер создан: False
