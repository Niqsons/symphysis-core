Замечания к схеме:

Предмет: короткие подписи задач в Mermaid при сохранении полного тела в tasks.md
и каноническом JSON графа. Предложены номер либо номер с явным коротким названием;
для старых задач без названия — номер.

Выбор владельца дословно, 2026-11-09:
«Номер и явное короткое название».

Дополнение владельца дословно:
«можно брать первые 100 символов, например. если у тебя нет идеи лучше.»

Продолжение по выбранному варианту: новая строка имеет вид
`- [ ] N.M **Название** — тело`, Mermaid показывает номер и явное название.
Это позволяет назвать действие отдельно от путей и кода в начале длинного тела.
У старых задач без явного названия остаётся номер, автоматическое переименование
старых tasks и изменение канонического JSON не выполняются.
