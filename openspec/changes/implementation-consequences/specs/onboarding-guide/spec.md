# Spec Delta

## Purpose
Пошаговое руководство `docs/GUIDE.md`: установка из клона репозитория и учебный проект, проведённый через все шаги OpenSpec настоящими командами.

## ADDED Requirements

### Requirement: Руководство ведёт установку из клона репозитория
Файл `docs/GUIDE.md` на русском SHALL вести установку из клона репозитория: клон, `npm i -g` тарбола форка из `vendor/`, инициализация проекта, `node installer/bin/symphysis.js install`, `check` (F-31.A, F-36.A, F-34.A, F-22).

<!-- проба запретов: исходы: F-97 открыт; канон — F-104 → security.md -->

#### Scenario: Установка на чистой машине
- **GIVEN** машина с Node и Python, без symphysis и без форка, с доступом к репозиторию и к реестру npm или зеркалу
- **WHEN** человек выполняет шаги установки из `docs/GUIDE.md`
- **THEN** `openspec --version` совпадает с пином, `check` печатает `check: ok` с кодом 0, в проекте есть `/opsx:continue`

#### Scenario: Шаг для разработчика
- **GIVEN** чистый клон без `upstream/openspec`
- **WHEN** разработчик собирается запускать тесты инсталлятора
- **THEN** `docs/GUIDE.md` называет шаг получения форка из ветки `openspec-fork` и отличает его от установки для пользователя
<!-- проба краёв, без кандидата: empty — пустого ввода в шагах установки нет -->

### Requirement: Учебный проект идёт настоящими командами и выводами
Файл `docs/GUIDE.md` SHALL вести один маленький учебный проект; приведённые команды и выводы SHALL быть взяты из настоящего прохождения, а читатель SHALL мочь повторить его сам (F-34.A).
<!-- проба краёв: форма=text, stateful, исходы: F-56 открыт, F-57 открыт -->
<!-- проба запретов: исходы: F-98 открыт -->

#### Scenario: Повтор читателем
- **GIVEN** машина после установки по `docs/GUIDE.md`
- **WHEN** читатель выполняет команды учебного проекта в указанном порядке
- **THEN** каждая команда отрабатывает, и читателю не нужны файлы вне учебного проекта и репозитория

#### Scenario: Прохождение проверяет руководство
- **GIVEN** готовый текст `docs/GUIDE.md`
- **WHEN** проводится прохождение по нему на Opus 5.5 или Sonnet 5.5
- **THEN** расхождение команды с текстом правит текст, и вывод в тексте взят из этого прохождения
<!-- проба краёв, без кандидата: empty — сценарий «Повтор читателем»; concurrency — прохождение идёт в одну сессию -->

### Requirement: Руководство покрывает все шаги OpenSpec
Файл `docs/GUIDE.md` SHALL описывать все шаги OpenSpec от установки до архивации, включая шаг `consequences` и выбор в `symphysis.yaml`; шаги после `tasks.md` SHALL быть в тексте и MAY быть описаны короче (F-34 и слово владельца к нему, F-24.A).

<!-- проба запретов: исходы: нет -->

#### Scenario: Шаги после tasks
- **GIVEN** `docs/GUIDE.md`
- **WHEN** читатель доходит до готового `tasks.md`
- **THEN** руководство не обрывается: дальше описаны реализация, синхронизация спек и архивация

#### Scenario: Выбор перед запуском
- **GIVEN** `docs/GUIDE.md`
- **WHEN** читатель доходит до шага `consequences`
- **THEN** руководство показывает `symphysis.yaml` и называет три выбора с умолчанием «включено»
<!-- проба краёв, без кандидата: ordering — порядок задаёт граф, `status` называет следующий шаг -->

### Requirement: Руководство называет проверенных клиентов
Файл `docs/GUIDE.md` SHALL показывать установку для Claude Code и параметр `--skills-dir` для других клиентов и SHALL называть, что opencode этим прохождением не проверен (F-34, следствие решения).

#### Scenario: Другой клиент
- **GIVEN** читатель с клиентом, отличным от Claude Code
- **WHEN** он читает раздел установки
- **THEN** руководство показывает `--skills-dir` и прямо говорит, что прохождение шло только на Claude Code
