# Spec Delta

## ADDED Requirements

### Requirement: Проба краёв даёт каждому требованию строку по всем восьми категориям
Скилл `symphysis-edge-probe` SHALL писать в файл покрытия рядом с журналом по строке на каждую пару требования и категории из восьми; человеку SHALL идти только кандидаты. Требование дополняет «Проба краёв поднимает категории по форме, кандидат — запись с четырьмя исходами»: строка есть у каждой категории, кандидат — только у применимой к форме (F-18.B).
<!-- проба краёв: форма=collection, stateful, исходы: F-64 открыт, F-65 открыт, F-66 открыт -->
<!-- проба запретов: исходы: нет -->

#### Scenario: Текстовое требование
- **GIVEN** требование формы `text`
- **WHEN** проба краёв завершена
- **THEN** в файле покрытия восемь строк этого требования; у `boundary`, `adjacency`, `ordering`, `precision`, `idempotency`, `concurrency` значение `неприменимо: <причина>`; кандидаты журнала возможны только у `empty` и `encoding` — предположение: файл покрытия называется `edge-probe.md`; решить при реализации
<!-- проба краёв, без кандидата: ordering — строка несёт ключ требования и категории, файл сравнивается по ключу; concurrency — прерывание называет сверка покрытия -->

### Requirement: Сырой список различает «не нашли» и «нашли, но не выбрали»
Строка покрытия SHALL нести одно из значений: `кандидат F-NN`, `не выбран: <край>; <причина>`, `не найдено: <что проверялось>` или `неприменимо: <причина>`; край, найденный и не вынесенный человеку, SHALL оставаться в файле покрытия (F-18.B, F-11). Дополняет требование о кандидатах пробы краёв: поднятый край может остаться без записи журнала.
<!-- проба краёв: форма=text, исходы: F-67 открыт, F-68 открыт -->
<!-- проба запретов: исходы: F-99 открыт -->

#### Scenario: Найдено, но не вынесено
- **GIVEN** край применимой категории, который модель нашла и не вынесла человеку
- **WHEN** проба краёв завершена
- **THEN** в файле покрытия строка `не выбран: <край>; <причина>`, в журнале записи нет

#### Scenario: Не найдено отличается от не выбрано
- **GIVEN** применимая категория, по которой модель края не нашла
- **WHEN** проба краёв завершена
- **THEN** в файле покрытия строка `не найдено: <что проверялось>`, и по файлу она отличима от строки `не выбран`

### Requirement: Текст пробы объясняет задачу подробнее
Текст скилла `symphysis-edge-probe` SHALL объяснять модели, что от неё требуется на каждом такте пробы: что такое строка покрытия, что значит каждое её значение и чем конкретный край отличается от напоминания (F-18.B и слово владельца к нему); предположение: мера подробности не задана; решить: судит владелец чтением текста.
<!-- проба краёв: форма=text, исходы: F-69 открыт -->
<!-- проба запретов: исходы: нет -->

#### Scenario: Чтение текста скилла
- **GIVEN** текст `skills/symphysis-edge-probe/SKILL.md`
- **WHEN** его читает человек или модель, не знакомая с пробой
- **THEN** для каждого значения строки покрытия есть определение и разобранный пример на данных одного требования
<!-- проба краёв, без кандидата: encoding — смысл перевода ведёт `TRANSLATION-NOTES.md` -->

### Requirement: Пробу краёв можно выключить, по умолчанию она включена
Скилл `symphysis-edge-probe` SHALL читать значение пробы краёв из `symphysis.yaml` в начале; при выключенном значении SHALL NOT заводить кандидатов и писать файл покрытия; проба запретов SHALL идти независимо от этого значения (F-18.B и слово владельца к нему, F-24.A).
<!-- проба краёв: форма=stateful, исходы: F-70 открыт -->
<!-- проба запретов: исходы: нет -->

#### Scenario: По умолчанию включена
- **GIVEN** проект без `symphysis.yaml`
- **WHEN** на шаге `specs` зовётся `symphysis-edge-probe`
- **THEN** проба идёт и файл покрытия появляется

#### Scenario: Выключена настройкой
- **GIVEN** `symphysis.yaml`, где проба краёв выключена
- **WHEN** на шаге `specs` зовётся `symphysis-edge-probe`
- **THEN** новых кандидатов `[<категория> · <форма>]` в журнале нет, файла покрытия нет

#### Scenario: Проба запретов не зависит от настройки
- **GIVEN** `symphysis.yaml`, где проба краёв выключена
- **WHEN** на шаге `specs` зовётся `symphysis-prohibition-probe`
- **THEN** проба запретов идёт как обычно
