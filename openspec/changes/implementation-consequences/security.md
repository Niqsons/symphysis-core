# Security

Чек-лист канона ИБ по `specs/` изменения `implementation-consequences`. Источники пунктов: instruction артефакта (пять пунктов) и шесть парковок адресату «ИБ» из пробы запретов (F-102…F-106). Канон в журнал не чеканится, он отмечается здесь. Каждая строка называет закрывающее требование и чем проверено: пробой, чтением файла с номером строки, командой или сценарием спеки. Где проверки ещё не было, так и написано, а тест назван задачей `tasks.md`.
