# Spec Delta

## Purpose
Ссылки на файлы в карточках и справке плагина: что становится ссылкой, какой файл можно открыть, где он открывается и как показаны файлы скиллов.

## ADDED Requirements

### Requirement: Ссылкой становится только путь из карты ядра
Плагин SHALL показывать ссылкой путь улики, файл шага и текст в обратных кавычках, только если он есть в карте `file_links` из вывода ядра; иначе SHALL оставаться `<code>` (F-11, F-27, F-28, F-44). Плагин SHALL NOT сам проверять файл и разбирать корни. Со старым ядром без поля всё SHALL оставаться текстом. Нажатие ссылки внутри варианта SHALL NOT выбирать вариант.

#### Scenario: Улика с файлом
- **GIVEN** улика `tools/a.py`, путь есть в карте
- **WHEN** просмотрщик показывает запись
- **THEN** путь показан ссылкой

#### Scenario: Текст не из карты
- **GIVEN** в вопросе `` `нет.md` ``, `` `constructor` `` и путь вне корня, в карте их нет
- **WHEN** просмотрщик показывает запись
- **THEN** они показаны `<code>` без ссылки

#### Scenario: Старое ядро
- **GIVEN** вывод ядра без поля `file_links`
- **WHEN** просмотрщик показывает запись
- **THEN** все пути показаны `<code>`, остальное работает, просьбы обновиться нет

#### Scenario: Файл шага в справке
- **GIVEN** файл шага, путь есть в карте вывода `step_help.py`
- **WHEN** вкладка показывает шаг
- **THEN** файл показан ссылкой; путь, куда файл только ляжет, ссылкой не показан

#### Scenario: Ссылка внутри варианта
- **GIVEN** вариант с файлом в тексте
- **WHEN** человек нажимает ссылку
- **THEN** файл открыт, вариант не выбран

### Requirement: Плагин открывает только файл из карты
Сообщение вкладки SHALL нести ключ карты, а хост SHALL брать путь из карты последнего показанного вывода. Хост MUST NOT открывать путь, которого нет в карте (F-44, F-54). Адрес из текста журнала SHALL NOT становиться путём.

#### Scenario: Ключ не из карты
- **GIVEN** вкладка показывает данные с картой
- **WHEN** приходит сообщение с ключом `../../секрет.txt`
- **THEN** файл не открыт

#### Scenario: Журнал сменился
- **GIVEN** файл был в карте журнала А, просмотрщик показывает Б
- **WHEN** приходит сообщение с ключом только из карты А
- **THEN** файл не открыт

### Requirement: Файл открывается рядом и без перевода фокуса
Файл SHALL открываться рядом с вкладкой, в предпросмотре и без перевода фокуса: следующий клик SHALL заменять ту же вкладку файла (F-45). С хвостом `:строка` SHALL открываться на этой строке. Выбора редактора SHALL NOT быть (F-14). Кнопка «Открыть scheme.md» SHALL оставаться прежней: там человек идёт править файл.

#### Scenario: Клик из просмотрщика
- **GIVEN** просмотрщик в одной колонке
- **WHEN** человек нажимает ссылку
- **THEN** файл открыт в соседней колонке, фокус остался в просмотрщике

#### Scenario: Следующий клик
- **GIVEN** файл открыт по ссылке в предпросмотре
- **WHEN** человек нажимает другую ссылку
- **THEN** новый файл заменил предпросмотр, новых вкладок нет

#### Scenario: Ссылка со строкой
- **GIVEN** ссылка `a.md:2`
- **WHEN** человек нажимает её
- **THEN** файл открыт на строке 2

#### Scenario: Кнопка «Открыть scheme.md»
- **GIVEN** вкладка со схемой
- **WHEN** человек нажимает «Открыть scheme.md»
- **THEN** файл открыт не предпросмотром, как и прежде

### Requirement: Скиллы шага показаны ссылками
Справка SHALL показывать скиллы шага из поля `skills`: найденный файл — ссылкой, не найденный — текстом (F-09, F-36, F-46, F-56). Файл вне проекта плагин SHALL открывать от каталога настройки `symphysis.toolsPath` (F-62). Такой файл может быть заглушкой, плагин SHALL показывать его как есть.

#### Scenario: Скилл в проекте
- **GIVEN** `skills` с путём от корня проекта
- **WHEN** человек нажимает ссылку
- **THEN** открыт `SKILL.md` проекта

#### Scenario: Скилл по настройке
- **GIVEN** `skills` с путём от каталога установки
- **WHEN** человек нажимает ссылку
- **THEN** открыт файл из каталога `symphysis.toolsPath`

#### Scenario: Скилл не найден
- **GIVEN** `skills` с пустым путём
- **WHEN** вкладка показывает шаг
- **THEN** имя показано текстом

#### Scenario: Старое ядро без поля
- **GIVEN** вывод без поля `skills`
- **WHEN** вкладка показывает шаг
- **THEN** блока скиллов нет, текст шага прежний
