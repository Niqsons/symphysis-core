## Вопросы, которые открылись

- Как спрятать от git файлы, созданные плагином: иначе агент с `git add -A` закоммитит абсолютный путь к Python. Запись F-66.
- Скрипт хука не должен выходить с кодом 2 ни при каком сбое: иначе он заблокирует запрос человека. Это требование для шага `specs`, выбора здесь нет.
- Поле `prompt` несёт текст человека: скрипту он не нужен, и в журнал событий его класть незачем. Это к чек-листу `security.md`.
