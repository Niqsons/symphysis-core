# F-69 · Запись хука без скрипта

## Найдено

- `research/F-69-probe/probe.log:2` «UserPromptSubmit operation blocked by hook:» — запись без файла скрипта блокирует запрос человека, и так на каждом запросе.
- `research/F-69-probe/probe.log:2` «can't open file» — причина: Python сам выходит с кодом 2, скрипт ещё не запущен, поэтому требование к скрипту этого не закрывает.
- `research/F-69-probe/probe.log:3` «"case": "запись с обёрткой, файла скрипта нет"» — запись, где Python запускается с `-I -c` и короткой обёрткой, запрос не останавливает.
- `research/F-69-probe/probe.log:4` «КАЛИНА-6161, вход True» — та же запись со скриптом на месте: вход и вывод доходят, `${CLAUDE_PROJECT_DIR}` разворачивается.
- `research/F-69-probe/probe.log:5` «РЯБИНА-7272» — скрипт вышел с кодом 2, обёртка его перехватила: запрос прошёл, вывод дошёл.
- `research/F-69-probe/probe.log:6` «"case": "настройки с комментарием: читает ли их клиент"» — ответ `НЕТ`: файл с комментарием клиент не читает, хук не сработал, запрос прошёл.
- `research/F-69-probe/probe.log:7` «"case": "настройки с ошибкой синтаксиса: что с запросом и хуком"» — то же.
- `research/F-69-probe/probe.log:8` «Это только превью первых 2 КБ.» — вывод около 60 КБ: модель видит начало, конец только в файле, если сама его откроет.
- `research/F-69-probe/docs-excerpts.txt:8` «capped at 10,000 characters» — предел из документации; проба не проверяла, что происходит ровно на нём.
- `research/F-69-probe/probe.log:9` «"case": "оболочка ловит сбой Python, файла скрипта нет"» — у opencode запрос проходит, если оболочка ловит сбой.
- `research/F-69-probe/probe.log:10` «"case": "оболочка ловит мёртвый путь к Python"» — то же при мёртвом пути.
- `research/F-69-probe/probe.log:11` «"case": "необработанное исключение в хуке prompt", "code": 1» — необработанное исключение в хуке `prompt` запрос человека останавливает.
- `research/F-69-probe/probe.log:12` «"case": "файл плагина не разбирается", "code": 0» — неразбираемый файл плагина запрос не останавливает.
- `research/F-69-probe/docs-excerpts.txt:4` «you can register a node script to the uninstall hook vscode:uninstall» — обещан только скрипт Node.
- `research/F-69-probe/docs-excerpts.txt:5` «which is when VS Code is restarted (shutdown and start) after the extension is uninstalled» — срабатывает после перезапуска; страница не говорит, что скрипту известен проект.
