# Security

| Пункт | Применимо / неприменимо — причина | Чем проверено |
| --- | --- | --- |
| Инъекции через содержимое файлов | применимо — требования «Страница показывает рекомендацию с причиной» и «Плагин показывает рекомендацию с причиной»: `why` пришёл из файла и теперь показывается везде. Путь показа не новый: страница ведёт его через `md`, плагин через компонент `Text`, а в режиме решений страницы `why` уже показывался | чтение `tools/playground-template.html:600` и `src/webview/Card.tsx:181`; сценарий основной спеки `decision-viewer` о `<img onerror>` в поле записи, правки в нём нет |
| Пути с `../` | неприменимо — изменение не открывает файлов и не разрешает путей: улики и карта ссылок не меняются | чтение `specs/` изменения: ни одно требование не называет путей |
| Токены и срок их жизни | неприменимо — токенов в изменении нет | чтение `specs/` изменения |
| Права | неприменимо — новых записей на диск и настроек нет, скиллы и плагин не получают новых прав | чтение `specs/` и `proposal.md` изменения |
| Бинарные файлы | неприменимо — изменение читает только JSON журнала, путь бинарных улик не меняется | чтение `specs/` изменения |
