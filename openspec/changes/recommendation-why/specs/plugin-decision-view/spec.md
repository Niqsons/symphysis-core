# Spec Delta

## ADDED Requirements

### Requirement: Плагин показывает рекомендацию с причиной
Карточка плагина SHALL показывать рекомендацию как `вариант — why` и MUST NOT показывать вместо причины поле `text`, даже если оно есть: так же, как страница (F-04, F-08, F-19).

#### Scenario: Карточка при поле `text`
- **GIVEN** рекомендация `{option: A, why: "дешевле откатить", text: "A — кратко"}`
- **WHEN** открывается карточка записи
- **THEN** под вариантами видно `A — дешевле откатить`, а `A — кратко` нет

#### Scenario: Поля `text` нет
- **GIVEN** рекомендация `{option: A, why: "дешевле откатить"}`
- **WHEN** открывается карточка записи
- **THEN** под вариантами видно `A — дешевле откатить`

### Requirement: Поиск плагина не читает поле `text`
Поиск плагина SHALL искать по причине рекомендации и MUST NOT находить запись только по полю `text`: найденное совпадение должно быть видно в карточке (F-18, F-20).

#### Scenario: Слово только в `text`
- **GIVEN** рекомендация `{option: A, why: "дешевле откатить", text: "A — кратко"}`
- **WHEN** человек ищет `кратко`
- **THEN** эта рекомендация в результатах не называется

#### Scenario: Слово в причине
- **GIVEN** та же рекомендация
- **WHEN** человек ищет `откатить`
- **THEN** запись найдена в поле «рекомендация»
