# Spec Delta

## ADDED Requirements

### Requirement: Страница показывает рекомендацию с причиной
Карточка страницы SHALL показывать рекомендацию как `вариант — why` и MUST NOT показывать вместо причины поле `text`, даже если оно есть (F-04, F-10, F-19).

#### Scenario: Есть поле `text`
- **GIVEN** рекомендация `{option: A, why: "дешевле откатить", text: "A — кратко"}`
- **WHEN** открывается карточка записи
- **THEN** под вариантами видно `A — дешевле откатить`, а `A — кратко` нет
