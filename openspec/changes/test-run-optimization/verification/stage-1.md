В RED обычная команда собрала 2192 теста, включая браузер и обёртку npm, а браузерный фильтр собрал ноль и завершился кодом 5. После разделения три `--collect-only` проверили 2109 обычных и 84 браузерных идентификатора против полной коллекции из 2193. Пересечение пустое, объединение равно полной коллекции. Обёртка инсталлятора отсутствует. Два новых теста жизненного цикла драйвера входят в обычную группу.

## Ревью

Отдельный ревьюер сверил задачи 2.1–2.5 и повторно проверил правки очистки. В управляемом Windows-режиме Node сохраняет результат браузерного сценария, а Python подтверждает остановку Job Object и затем удаляет профиль. На POSIX код сохраняет PID лидера до очистки группы и отдельно проверяет отсутствие живых членов. Для двух сценариев используется сохранённый вывод драйвера.
