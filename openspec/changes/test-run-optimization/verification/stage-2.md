Исполнитель зафиксировал RED на отсутствии CLI, ошибочной ширине отбора и отсутствующем входе VS Code. Отдельный ревьюер проверил планировщик, декларации, исполнение и повторные правки по найденным случаям. Журнал `calibration-fixes` с каталогом на месте `decisions.json` проверен отдельно, preflight возвращает отказ.

Автоматический полный набор содержит обычный и браузерный pytest, инсталлятор, unit VS Code и пять локальных e2e. Native-приёмка `e2e:hook` использует внешние модели Claude Code и OpenCode, поэтому остаётся явной отдельной командой.
