# symphysis-viewer — где образец изменён

Источник-образец — скилл `playground` плагина Playground (marketplace
`claude-plugins-official`), файл `playground/SKILL.md` (корень `playground/`
в `tools/journal-roots.json`); его `templates/*.md` источником не стали: ни один
не знает статусов, улик, зависимостей и антиподов
(`docs/playground-template-llm-pipeline.md`, «Когда применять»). Это не перевод,
а свой скилл и свой шаблон (F-26, слово владельца 2026-10-30: Playground —
«источник вдохновения, а не точка расширения»). Ниже — что взято как образец
и что сделано иначе. Строки — по `playground/SKILL.md`.

## Перенесено без изменения смысла

Один HTML-файл без зависимостей (`:29`), живой пересчёт без кнопки
«применить» (`:30`), промпт только из отличий (`:31`), кнопка копирования
с откликом (`:32`), тёмная тема и системный шрифт (`:34`), один объект
состояния (`:38`), пересчёт одной функцией (`:43-47`), «External
dependencies → if CDN is down, playground is dead» (`:75`).

## Не перенесено

Набор шаблонов `templates/*.md` (`:18-23`) — у журнала свой шаблон; `open`
после записи (`:25`); presets (`:33`); советы про числовые контролы
и качественные слова рядом с числами (`:61-63`); «hide advanced in
a collapsible section» (`:72`) — скрытый вариант есть решение за человека,
свёрнута только парковка, и то открыта, когда непуста.
