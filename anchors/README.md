# anchors

Якоря записей журнала в мастер-спеках: после синхронизации голые ссылки `F-NN` блоков
изменения в `openspec/specs/<capability>/spec.md` переписываются в форму
`<изменение>/F-NN`, чтобы номера разных журналов не сталкивались. Скрипт — `anchor_refs.py`,
зовётся по строке правила `rules.specs` и подсказке архива; разбор ссылок и правило имени
изменения берёт из модулей `trace` и `openspec-run`.
