# anchors

Якоря записей журнала в мастер-спеках: после синхронизации голые ссылки `F-NN` блоков
изменения в `openspec/specs/<capability>/spec.md` переписываются в форму
`<изменение>/F-NN`, чтобы номера разных журналов не сталкивались. Скрипт — `anchor_refs.py`,
зовётся шагом sync и подсказкой архива; разбор ссылок и правило имени
изменения берёт из модулей `trace` и `openspec-run`.

`sync_check.py` только читает результат переноса: проверяет выбранные требования,
сценарии, переименования и происхождение якорей; выдаёт match, mismatch или review.
Смысловое слияние текста и случаи без доказанного происхождения остаются суждением модели.
