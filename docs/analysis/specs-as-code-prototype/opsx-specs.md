# /opsx:specs

Вызов: `/opsx:specs <change>`.

Исполнитель MUST загрузить скилл `symphysis-specs` и передать имя изменения, выбранный store и ограничения вызывающего задания без изменения; иначе оболочка потеряет область авторства. Весь порядок, включая ограничение «только авторство», определяется телом `symphysis-specs`.
