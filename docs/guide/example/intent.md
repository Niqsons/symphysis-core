# Намерение: add-overdue

## Намерение

> Нужна команда `overdue`: показывает напоминания, срок которых уже прошёл, по одному на строку, самые старые сверху. В `reminders.py` уже есть `load_reminders` и `parse_due`, наверное, стоит опереться на них, а не писать разбор файла заново.
> — задача учебного проекта, `docs/guide/example/intent.md`

## Критерии готовности

- `python reminders.py overdue` печатает просроченные напоминания, самые старые сверху (задача учебного проекта)
- `python reminders.py list` работает как раньше (задача учебного проекта)
